# Evidence index

Read the [measurement method](../../docs/measurements-2026-11-06.md) before
comparing values. Raw Flutter timings are not physical-display FPS. Public
fixtures and browser-only probes require no application account or backend.

| Files | Meaning |
| --- | --- |
| `windowed-mac-chrome157-final*.json` | Final app, Chrome for Testing 157.0.8103.38, headless; broad smoke and separate repeated Trina/chart comparisons |
| `windowed-linux-chrome157-final*.json` | Final app, the same Chrome version, visibly running with NVIDIA GPU, monitor on and desktop unlocked |
| `windowed-*-reference.json` | Pinned upstream 200-node demo, fresh browser process per case, three repetitions per mode |
| `windowed-{mac,linux}-{chrome,edge,firefox157}.json` | Initial installed/patched browser dashboard campaigns; before the Trina Total-format fix; Linux Chromium is headless SwiftShader |
| `windowed-*-hybrid[01].json` | Same candidate bundle, bitmap/hybrid flag, three repetitions per configuration |
| `windowed-mac-chrome157-hybrid-confirmation.json` | Follow-up to the variable Chrome 156 chart result; alternating flags and fresh process per repetition |
| `mac-safari27-final-native.jsonl` | Corrected windowed final-app Safari samples, copy probe and separate buffer-lifecycle diagnostic |
| `linux-firefox159-native.jsonl` | Current vendor Firefox final-app proofs, default fallback, corrected windowed in-page samples and probes |
| `linux-firefox159-candidate-native.jsonl` | Current vendor Firefox same-candidate worker A/B; each URL has three in-page repetitions |
| `mac-native.jsonl` | Earlier native Safari/Firefox functional evidence; **do not use its unwindowed timings for performance**; also contains the Mac Firefox copy probe |
| `linux-native-nightly.jsonl` | Vendor Nightly 162.0a1 copy probe; one context, 100 measured calls per case |
| `*-copy.json` | Automated microprobe, three contexts; raw calls and per-case medians/p95; late direct-source snapshots are not display correctness assertions |
| `*-composition.json` | Real controls, overlay action, native iframe typing, scene resize and restored-plot equality |
| `*-minimal.json` | 36 marker states per configuration, first sampled screenshot and bounded convergence; two initial stale observations retained |
| `engine-tests-firefox159.log` | Focused vendor Firefox engine assertions; local source paths replaced with placeholders; 49 passes, two intentional skips |
| `summary.json` | Repetition-level means/rates/jitter summarized as medians; generated by `tool/summarize.mjs`; JSONL native samples are reported separately |
| `bundle-size*.json` | Core app/runtime compression calculation; common assets and duplicate fallback excluded; final file distinguishes generic and Chromium CanvasKit |
| `builds-*.json`, `environment.json` | Artifact identities, SDK/browser/hardware identities and capture qualifications |
| `upstream-status.json`, `browser-issue-status.json` | Inspected public issue/PR status and exact candidate revisions |
| `linux-chrome157-graphics.json`, `linux-display-*.json` | Headless SwiftShader versus visible NVIDIA backend and filtered desktop-state evidence |
| `screenshots/` | Fresh public-fixture screenshots; basenames recorded in timing JSON refer to this directory |

The reports retain rejected-method explanations rather than treating exploratory
numbers as final measurements. `correct=false` in the old direct-copy probe
means a late source readback did not match; buffer preservation was off, so it
does not establish a blank physical display. All listed bitmap timing controls
keep their own pixel observations.

`manifest.sha256` covers the published evidence files. Source submodules and
package locks supply dependency identities; regenerated binaries and downloaded
browsers are intentionally excluded from Git.
